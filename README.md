### ✨ Features

- **Smart Search** – Case-insensitive search, works for `japan`, `JAPAN`, `Japan`
- **Auto Suggestions** – Live suggestions while typing
- **Complete Country Card** – Flag, Capital, Population, Region, Currency, Density
- **View More Details Modal** – Language, Area, Timezone, Borders, Continent
- **Google Maps Integration** – Fixed `goo.gl` issue, now uses `google.com/maps/place`
- **Wikipedia Integration** – Full Wikipedia article inside modal + Open in new tab
- **Favorites** – Save / Remove favorites with LocalStorage persistence
- **Fully Working Navbar** – Explore, Favorites, Settings all functional
- **Offline Fallback** – India, USA, Japan, France, Germany, UK work even if API fails
- **Dark Premium UI** – Clean, modern, responsive design

### 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **APIs:** [RestCountries](https://restcountries.com) v3.1, [FlagCDN](https://flagcdn.com)
- **Storage:** Browser LocalStorage
- **Fonts:** Inter
